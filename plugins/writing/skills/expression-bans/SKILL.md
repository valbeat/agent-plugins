# 表現の禁止事項（指定したリポジトリだけに掛ける）

土台の `japanese-tech-writing` に重ねる上乗せ規範。ここにあるのは媒体の文体ではない。スライド、台本、応募文はそれぞれ別の文体を持ち、その規範は各リポジトリにある。ここで定めるのは、それらに共通して掛けると決めた禁止事項だけである。

**リポジトリの規範がこのスキルを指定している場合にだけ適用する。**比喩を説明の手段として認めている媒体（ブログの入門記事など）には持ち込まない。

## 比喩の全面禁止

比喩・メタファー・アナロジー・擬人化を、このスキルを指定したリポジトリの成果物（スライド本文、タイトル、キーフレーズ、スピーカーノート、台本、記事、CFP 本文など）で使わない。**タイトルとキーフレーズも例外にしない。** 知識ベースの文書とスキル定義の地の文にも適用する（他者の発言・過去成果物の引用と記録は除く）。概念に名前を付けるときも比喩を使わず、内容を直接表す名前にする（例: 風呂敷フェーズ→拡張フェーズ、波の設計→感情曲線の設計、2 階建て構造→概要→詳細の二段構成、フライトマップ→現在地の共有）。

- 陳腐な借り物（「羅針盤」「地図」「土台」「車の両輪」「潤滑油」「スパイス」「レシピ」「筋トレ」等）に限らず、オリジナルの比喩（「同じ根から生えた」「証明まで登る」「家系図」等）も対象とする。
- 概念間の関係は中立な言葉で直接書く（根→起点、地図→全体像、「同じ根から生えた」→「どちらも〜から生まれた」、「証明まで登ると何が手に入るか」→「証明で何が手に入るか」）。
- 抽象概念は比喩ではなく、実コード・実例・数字で噛み砕く。
- 言い換えるとかえって不自然になるほど慣用に定着した語（「入り口」「流れ」「視点」等の死喩）は対象外。読み手に元の画像を想起させる生きた比喩だけを禁止する。
- 他分野で定義が確立した術語をその定義のまま使うことは、比喩ではなく専門用語の転用として扱う（下記「概念の名付け方」の 3 条件を満たす場合に限る）。禁止範囲を緩める例外ではなく、そもそも比喩に当たらないという分類。

背景: 2026-07 のスライド制作で、生成した比喩（登る・根・地図・家系図）を除去する修正コミットが繰り返し発生した。列挙方式では生成時に防げないため、全面禁止に改めた。

## 概念の名付け方

比喩は例外なく禁止する。その上で概念に名前を付ける手段が 2 つある。どちらも比喩の抜け道ではなく、比喩とは別の技法。

**術語の借用は比喩ではない。**他分野で定義が確立した語を、その定義のまま構造の一致を示すために使うのは、専門用語の転用であって比喩ではない。制約理論の「ボトルネック」「在庫のムダ」、数学の「積分」、Kubernetes の「Reconciliation Loop」がこれにあたる。次の 3 条件をすべて満たすときに限る。

1. その分野で定義が確立している（辞書的な意味が一意に定まる）
2. **出典の分野を名指しできる**（制約理論の、Kubernetes の、と言える）
3. 聴衆に伝わらない語なら、一文で定義してから使う

**判定基準は出典分野を名指しできるかどうか。**「羅針盤」「小人さん」「ファンネル」には出典分野がなく、読み手に情景を想起させるだけなので比喩であり禁止側。「〜のようなもの」と添えたくなる語も比喩。名指しできる術語は、その語のまま使い、比喩の形（「〜のような」）にしない。

**既存の対の語に役割を与える。**造語を作らず、既にある語のペアを定義して区別する。「自動化（automation）と自働化（autonomation）」のように、聞いた瞬間に差が想像でき、定義を与えれば正確になる語を選ぶ。対の一方だけが情景を呼び起こす場合（「伴走」など）は、対として定義しても比喩性が残るため、より中立な語を探す。

## 記号

土台のダッシュ、中黒、絵文字の規範に加えて、次を守る。

- 全角スラッシュ（／）で概念を並列しない。読点や「と」「や」でつなぐ。
- カギ括弧「」で語を切り出す強調を多用しない。「」内に『』を入れ子にしない（書名・引用内引用の慣用は除く）。
- 日本語の文中でコロンを英語式に使わない（「以下の 3 つ：」のような文末コロン、コロン後の半角スペース）。導入は句点で切るか「次の〜」で受ける。

## LLM っぽい表現の追加分

土台の「LLM っぽい表現の禁止」の一覧に加えて、次の型を使わない。

- **万能語**：「本質」「解像度」「最適化」「シームレス」「手触り」を中身の説明なしに使う
- **中立を装う型**：「メリットもあればデメリットもあります」「賛否が分かれるところです」で判断から逃げる。推奨か非推奨かを条件付きで言い切る
- **保険の予防線**：「一概には言えませんが」「状況によります」を根拠の提示なしに置く
